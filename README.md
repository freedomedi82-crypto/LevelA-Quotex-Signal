# Level A Quotex Signal

Android signal and research application.

## Build

The project is built automatically with GitHub Actions on pushes to `main` or by manual workflow dispatch.

## Current stage

- Android project bootstrap
- Java 17
- Android Gradle Plugin 9.4.0
- compileSdk / targetSdk 37
- Debug APK workflow

The application is intended as a signal/research tool. It does not guarantee trading outcomes or profitability.
